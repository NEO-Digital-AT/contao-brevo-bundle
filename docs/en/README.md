# Contao Brevo Newsletter – documentation

Contao Brevo Newsletter signs visitors up for a newsletter list in Brevo with
double opt-in. Brevo sends the confirmation e-mail and adds the contact to the
chosen lists once the visitor confirms. The extension offers two ways: the
front-end module **Brevo Newsletter** with its own form, and the form field
**Brevo sign-up**, a checkbox for any form of Contao's form generator.
