# Contao Brevo Newsletter – Dokumentation

Contao Brevo Newsletter meldet Besucher mit Double-Opt-in bei einem Verteiler in
Brevo an. Brevo verschickt die Bestätigungs-E-Mail und trägt den Kontakt nach
der Bestätigung in die gewählten Listen ein. Die Erweiterung bietet zwei Wege:
das Frontend-Modul **Brevo E-Mail-Anmeldung** mit eigenem Formular und das
Formularfeld **Brevo-Anmeldung**, eine Checkbox für jedes Formular des
Formulargenerators.
